# Pinch-By-Blaze-WorkFlow
Body Piercing Studio Booking Website
A scheduling and workflow automation system for small professional body piercing service businesses using Wix AD and Squarespac. Designed to streamline bookings, task tracking, and client communication and reduce overhead from Wix.
